Quiero diseñar un sistema web completo, moderno y profesional llamado:

“MediControl SV – Sistema Integral de Gestión de Consultorio Médico y Expediente Clínico Digital”

OBJETIVO GENERAL
Crear una plataforma web para un consultorio médico privado que centralice los procesos administrativos y clínicos principales. El sistema debe permitir administrar pacientes, médicos, citas, horarios, expedientes clínicos, consultas, signos vitales, recetas médicas, órdenes de estudios, resultados de estudios, seguimientos, pagos, notificaciones, reportes y auditoría.

Debe ser una aplicación pensada para consultorios pequeños y medianos que actualmente manejan parte de su información mediante llamadas, WhatsApp, documentos impresos, archivos separados o registros manuales.

El objetivo es facilitar el proceso completo:

Paciente agenda cita →
Recepción confirma la cita →
Paciente llega al consultorio →
Recepción registra su llegada →
Médico visualiza al paciente en sala de espera →
Médico abre expediente →
Realiza y registra la consulta →
Puede generar receta →
Puede solicitar estudios →
Puede establecer seguimiento →
Paciente posteriormente consulta sus citas, recetas y estudios.

IMPORTANTE:
El sistema NO debe diagnosticar automáticamente enfermedades mediante inteligencia artificial.
Los diagnósticos, tratamientos, recetas e indicaciones son registrados exclusivamente por el médico.
La aplicación sirve para administración, almacenamiento, organización y seguimiento de información.
